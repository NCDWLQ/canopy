# 右侧对话区域消息气泡与极简输出风格改造

## Goal

重构右侧会话区域的消息展示风格：将用户发送的消息改为右对齐的消息气泡，保留现有背景色；将 LLM/助手的输出改为直接在背景中渲染的极简风格（无卡片边框和独立背景框，类似 ChatGPT/Claude），同时去除视觉上的“用户”和“助手”文本标签，并保留完整的无障碍可访问性与分支/编辑操作能力。

## Requirements

### 1. 用户消息展示
- 采用消息气泡形式展示，靠右对齐（`ml-auto`），自适应内容宽度（最大宽度 `max-w-[85%]` 或 `max-w-2xl`），位于中央阅读列（`max-w-4xl`）内。
- 保留现有的背景色（`bg-muted`）并采用现代圆角气泡样式（`rounded-2xl`）。
- 移除原先在消息顶部的“用户”文本标签。
- 保留完整的无障碍属性（`aria-label="用户消息"` 和 `role="article"`）。

### 2. 助手 / LLM 消息展示
- 采用直接在背景中展示的极简风排版，不显示独立的卡片背景与边框（`border-none`、`bg-transparent`、`shadow-none`）。
- 靠左全宽展示，内容（富文本 Markdown、代码块、列表等）直接呈现在对话主背景上。
- 移除原先在消息顶部的“助手”文本标签。
- 保留完整的无障碍属性（`aria-label="助手消息"` 和 `role="article"`）。
- 临时生成状态（“正在思考”、流式生成、恢复状态、失败提示及“重新生成”/“重试恢复”按钮等）同样直接平滑展示在背景中，去除卡片外框。

### 3. 操作按钮与交互（分支与编辑）
- 移除消息顶部的操作栏占位，改为在消息下方提供操作栏。
- 助手消息的操作按钮（从此处创建分支、编辑为新分支）位于内容正下方；用户消息的操作按钮位于气泡右下方。
- 操作按钮默认保持低调/低透明度或悬停显示（`group-hover:opacity-100` / `focus-within:opacity-100`），保证阅读区域整洁清爽。
- 编辑模式与分支模式下的输入表单与提交/取消操作保持可用且样式适配。

### 4. 纯净极简设计
- 不额外添加头像或身份图标，界面保持纯粹、优雅与现代感。
- 保证明暗主题下的对比度与可读性良好。

## Acceptance Criteria

- [x] 用户消息以右对齐气泡展示，带有 `bg-muted` 背景与舒适内边距，移除“用户”标签文本。
- [x] 助手消息为全宽直接背景渲染，无卡片框与边框，移除“助手”标签文本。
- [x] 流式输出及各种瞬态（思考中、失败重试等）无边框正常显示。
- [x] 编辑为新分支和从此处创建分支功能交互完整，按钮悬停/聚焦显示正常。
- [x] 屏幕阅读器与测试中的可访问名称（如 `aria-label="用户消息"`、`aria-label="助手消息"`）完全保留且语义正确。
- [x] 项目现有测试套件全部通过（`pnpm test` / `pnpm typecheck` / `pnpm lint`）。
